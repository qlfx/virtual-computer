# 形式化证明检查计划

当前代码已能登记位布局、分配变量并读写比特。`programs/prooftest.py` 是早期数据草稿。以下内容记录待实现的逻辑层和指令设计。

## 从蕴含开始

第一个完整样例给定 `f : P → Q` 和 `g : Q → R`，检查 `λ p : P. g(f(p))` 的类型为 `P → R`。

- 命题节点记录原子符号或蕴含的左右公式引用。
- 证明项使用变量引用、应用和抽象。应用检查参数类型，抽象在局部环境里引入带类型的假设。
- 公式与证明项分别登记。检查器从证明项和环境推导类型。
- 验收时接受 `g(f(p))`，并在 `P` 与 `Q` 不同时拒绝 `g(p)`。

## 群与子群判定

群结构由载体 `T`、乘法、单位元 `e`、求逆以及群公理的证明字段组成。类型定义保存有序字段和类型表达式引用，实例保存对应的值或证明引用。例如左逆元证明字段的类型为 `∀ x : T, mul(inv(x), x) = e`，其中的名称指向同一结构的前置字段。逻辑字段的类型关系由检查器解释，位布局负责储存节点与引用。

给定群 `G`，用 `H : T → Prop` 表示载体上的子集。额外给出非空见证 `a : T` 和 `ha : H(a)`。逆元乘积封闭条件的证明具有类型：

```text
p : ∀ s,t : T, H(s) → H(t) → H(mul(inv(s), t))
```

| 要得到的证据 | 使用封闭条件 | 等式改写依据 |
| --- | --- | --- |
| 单位元属于 H | 用 a 和 ha 两次，得到 H(a⁻¹a) | a⁻¹a = e |
| 逆元封闭 | 用 s 和 e 及其成员证明，得到 H(s⁻¹e) | s⁻¹e = s⁻¹ |
| 乘法封闭 | 用 s⁻¹ 和 t 及其成员证明，得到 H((s⁻¹)⁻¹t) | (s⁻¹)⁻¹ = s，在乘法左侧改写 |

将三项证据交给子群构造规则。结合律由 G 继承。双重求逆的等式可先引用已证明的引理，后续再检查它从群公理推出的过程。

## 面向检查的指令

第一版由证明程序显式指定定理、参数和改写位置。核心操作包括按编号读取公式和证明、实例化带绑定变量的公式、比较类型，以及依据等式证明改写指定子表达式。自动搜索定理和匹配候选位置可以在此基础上独立发展。

群论部分的第一项验收是使用 `p(a, a, ha, ha)` 和左逆元定律的实例得到 `H(e)` 的证明。将等式换成左侧表达式与指定位置不符的证据时，检查器应拒绝。
